# DieStak Updates

This public repository hosts Windows installers and release notes for DieStak. The application source code remains in the private [DieStak repository](https://github.com/PixelFuzz/DieStak).

## Install or update

- New users: download the latest DieStakSetup installer from [Releases](https://github.com/PixelFuzz/DieStak-Updates/releases/latest).
- Existing users: use **Update DieStak** in the app. It checks for a release, verifies the installer checksum, installs the update, and reopens the app. A GitHub account is not required.

Only public release installers and their release notes are published here. Collection databases, photos, settings, and source code are not included.
